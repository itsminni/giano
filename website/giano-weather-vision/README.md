# Giano Website

[English](#english) · [Italiano](#italiano)

## English

Giano's website, built with React and TanStack Start.

## Run locally

Install Node.js 24 and Bun. From the repository root:

```bash
cd website/giano-weather-vision
bun install --frozen-lockfile
bun run prepare:data
bun run dev --host 127.0.0.1
```

Open http://127.0.0.1:8080.

`prepare:data` checks and copies data from `artifacts/website/giano-history`.
The history exporter includes the available ERA5-Land signals from the processed
NetCDF files. Charts can show them as an optional overlay, without new inference.
To use another path:

```bash
GIANO_SITE_DATA=/path/to/giano-history bun run prepare:data
```

## Edit the text

- Italian: [src/content/it.ts](src/content/it.ts).
- English: [src/content/en.ts](src/content/en.ts).
- Guide commands: [Guide.tsx](src/components/giano/Guide.tsx).
- Search engine title and description: [index.tsx](src/routes/index.tsx)
  and [__root.tsx](src/routes/__root.tsx).
- Team and tutors: [data.ts](src/components/giano/data.ts).

Edit the sentences in both languages, keeping keys and placeholders such as
`{n}` unchanged. Counts and metrics come from the exported data.

The animated demo is in [Demo.tsx](src/components/giano/Demo.tsx).

## Pages and data

The map reads the catalog from `src/generated/catalog.json` and loads examples
and historical series from `public/data/giano`. These folders are generated by
`prepare:data` and are not included in Git. Series are split by year.

Example direct links:

```text
/?tab=mappa&station=T0063&variable=temperature
/?tab=guida
```

## Check and prepare the build

```bash
bun run check
bun test
bun run lint
bun run build
```

## GitHub Pages

The static version keeps the map, charts and complete series. Historical data
is gzip-compressed and decompressed by the browser when needed. Recent browsers with `DecompressionStream` support are required.

From the website directory, after `prepare:data`:

```bash
bun run build:pages
tar -czf dist/giano-pages.tar.gz -C dist/client .
```
